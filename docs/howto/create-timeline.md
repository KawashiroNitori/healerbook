# 如何新建空白时间轴

当你想从头规划一场副本的减伤，而不是从 FFLogs 导入时：

1. 在首页点击 **「新建时间轴」**
2. 填写 **时间轴名称**（比如 "M12S 本体 H2 欠我钱减伤轴"）
3. 在 **「副本」** 下拉菜单中选择你要规划的副本
   - 副本按分组展示，比如「阿卡狄亚零式 重量级 (7.4)」下有 M9S ~ M12S
   - 选择副本会自动采用对应等级；不绑定副本时，在「其他」分组选择「不指定副本 - Lv70 / Lv80 / Lv90 / Lv100」
4. 点击 **「创建」**

创建后会在新标签页打开编辑器。时间轴是空的，你需要自己添加伤害事件和减伤技能。

创建后也可以在设置中修改绑定副本和等级，详见 [设置时间轴等级](./timeline-level)。

> 副本可选项以创建菜单为准；如果绑定副本暂不支持统计数据，顶部会出现黄色提示条。
