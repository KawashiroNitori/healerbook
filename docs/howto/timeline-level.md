# 如何设置时间轴等级

时间轴支持 **70、80、90、100** 四档等级。技能列表和减伤计算会使用所选等级对应的技能效果，方便规划不同同步等级的副本。

## 新建时选择等级

在「新建时间轴」的副本菜单中选择副本，时间轴会采用该副本对应的等级。

如果不绑定副本，在「其他」分组中选择 **「不指定副本 - Lv70」**、**「不指定副本 - Lv80」**、**「不指定副本 - Lv90」** 或 **「不指定副本 - Lv100」**。

## 修改已有时间轴

1. 点击工具栏最后的 **⚙️ 设置** 按钮。
2. 在「基本」中选择 **等级**。
3. 点击 **「保存」**。等级与原值不同时，保存按钮会变为红色，并弹出二次确认。
4. 确认提示后，修改才会生效；点击「取消」关闭设置会放弃本次修改。

修改绑定副本时，草稿等级会自动切换到该副本的等级，也可以再手动调整。解除副本绑定会保留当前选择的等级。

## 等级变化会影响什么

- 只显示所选等级可用的技能；技能名称、效果、复唱时间或充能等属性会按对应等级调整。
- 伤害计算和导出内容会采用当前等级下的技能数据。
- 保存等级变更时，已经放置但在新等级下不可用的技能会被移除。升回原等级不会自动恢复这些技能，请在确认前检查安排。

设置对话框中的绑定副本、等级、小队阵容和技能数值都在点击保存后生效。只读时间轴可以查看设置，但不能保存修改。

没有等级记录的旧时间轴默认采用 100 级。

## 已知问题

由于第三方 API 暂未提供等级分歧数据，技能悬浮窗中的技能描述始终以满级显示，但实际技能效果不受影响。
