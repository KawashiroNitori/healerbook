# 如何管理小队阵容

阵容决定了时间轴上显示哪些职业的技能轨道，以及有哪些减伤技能可用。

## 查看阵容

点击工具栏最后的 **⚙️ 设置** 按钮，在左侧选择 **「小队阵容」**。这里显示队员数量和职业图标，悬浮图标可以查看职业名称。

## 调整阵容

1. 点击阵容列表右侧的 **「调整阵容」**，展开职业选择区域。
2. 按角色分组（坦克 / 治疗 / 近战 / 远敏 / 法系）点击职业图标，添加队员。
3. 点击已有队员的职业图标，移除该队员。只有展开调整区域时才能删除队员。
4. 阵容最多 8 人，满员后无法继续添加。
5. 点击设置对话框的 **「保存」**，修改才会生效；点击「取消」会放弃本次修改。

再次点击「调整阵容」可以收起职业选择区域，已编辑的阵容草稿会保留。技能数值区域会随草稿阵容显示对应职业的技能。

只读时间轴可以查看阵容，不能添加或删除队员。

需要控制技能轨道的显示范围时，使用工具栏的 [过滤菜单](./filter-menu)。
