# 如何使用阶段

长战斗（比如绝境战）往往有十几分钟，单靠翻时间轴很难看出「现在打到了哪个阶段」。阶段功能会在时间轴上标出每个阶段从哪里开始，并让你一步跳过去。

阶段只是时间上的**标记**：添加、移动、删除阶段都不会影响伤害事件、技能或任何减伤计算。

## 阶段从哪里来

- **从 FFLogs 导入**：报告里带有阶段数据的副本，导入时会自动带上阶段。
- **从副本模板新建**：新建时间轴时选择的副本如果已有带阶段的模板，会一并带入。
- **手动添加**：任何时间轴都可以自己添加阶段，见下文。

阶段名会按导入或新建时的界面语言显示；之后切换语言，已有的阶段名不会变化，你也可以随时手动改名。

::: tip
从 FFLogs 导入的时间轴默认处于回放模式，此时阶段只能查看和跳转。需要编辑阶段时，先[退出回放模式](./replay-mode)。
:::

## 在哪里看到阶段

- **时间轴**：每个阶段开始处有一条彩色竖线和一小段渐变色，阶段名写在顶部时间标尺上。
- **缩略图**：底部缩略图上同样标出每个阶段的起点和简称。
- **表格视图**：每个阶段在开始时间处插入一行阶段行；往下滚动时，当前阶段行会停在表头下方。
- **工具栏**：最右侧的阶段按钮显示你当前所在的阶段。

阶段按时间顺序依次使用不同颜色，便于区分相邻阶段。

## 跳转到某个阶段

点击工具栏最右侧的阶段按钮，在下拉列表中选择一个阶段，视图会滚动到该阶段的开始处。

## 添加阶段

- **时间轴**：在时间标尺或任意轨道的空白处**右键**，选择 **「在此处添加阶段」**。
- **表格视图**：在伤害事件行上**右键**，选择 **「在此行前添加阶段」**。
- **工具栏**：打开阶段下拉列表，选择 **「在当前位置添加阶段」**；时间轴还没有任何阶段时，直接点击工具栏上的 **「＋ 阶段」**。

新阶段会按位置自动命名为 `P1`、`P2` 这样的名字，并立即进入改名状态，其他阶段的名字不会被改动。

## 修改阶段

| 操作         | 时间轴                                | 表格视图                       | 工具栏下拉列表               |
| ------------ | ------------------------------------- | ------------------------------ | ---------------------------- |
| 改名         | 双击阶段名，或选中后点击铅笔图标      | 双击阶段名，或点击行尾铅笔图标 | 悬停在阶段上，点击铅笔图标   |
| 修改开始时间 | 左右拖动阶段名                        | 单击时间，直接输入新时间       | —                            |
| 删除         | 选中后点击垃圾桶图标，或按 **Delete** | 点击行尾垃圾桶图标             | 悬停在阶段上，点击垃圾桶图标 |

以上操作也都可以通过**右键**阶段名或阶段行找到。

- 改名时按 **Enter** 确认、**Esc** 取消；名字清空视为取消。
- 阶段不能越过相邻阶段，且与相邻阶段至少相隔 1 秒；超出范围时会自动调整到允许的位置。
- 删除前会弹出确认框。
- 所有修改都可以用 **Ctrl + Z** 撤销，并会实时同步给协作者。
